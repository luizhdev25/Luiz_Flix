# Luiz Flix

Catálogo de filmes e séries feito com HTML, CSS e JavaScript.

## Funcionalidades

- Home
- Movies
- TV Shows
- Cards com pôster
- View Details
- Janela de detalhes
- Descrição
- Ano
- Gêneros
- Duração ou temporadas
- Nota
- Layout responsivo
- Código simples e organizado

## Filmes

- Avengers: Infinity War
- The Dark Knight
- The Godfather
- The Hangover
- Mission: Impossible — Fallout

## TV Shows

- The Mentalist
- Smallville
- Breaking Bad
- Regular Show
- Loki

## Imagens

Coloque os pôsteres JPG dentro da pasta `images` usando os nomes já definidos no `index.html`.

## Como executar

Abra `index.html` ou use o Live Server no VS Code.
