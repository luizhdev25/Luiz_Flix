# Luiz Flix

Movie and TV show catalog made with HTML, CSS and JavaScript.

## Features

- Home
- Movies
- TV Shows
- Poster cards
- View Details
- Details window
- Description
- Year
- Genres
- Runtime or seasons
- Rating
- Responsive layout
- Simple and organized code

## Images

Put the JPG posters inside the `images` folder using the filenames already defined in `index.html`.

## How to run

Open `index.html` or use Live Server in VS Code.
