# 🎬 Luiz Flix

**Luiz Flix** is a movie and TV show catalog website inspired by streaming platforms. It provides a simple and modern interface where users can explore a collection of movies and TV shows and view detailed information about each title.

## ✨ Features

- **Modern Interface:** Dark theme with a red accent color.
- **Movie Catalog:** Browse a collection of movies with posters, release years, and genres.
- **TV Show Catalog:** Explore different TV shows and their information.
- **Title Details:** Click the "View Details" button to open a modal with additional information.
- **Interactive Modals:** Close the details window using the close button, clicking outside the modal, or pressing the `ESC` key.
- **Responsive Design:** Layout adapted for desktop, tablet, and mobile screens.
- **Smooth Hover Effects:** Interactive animations on movie and TV show cards.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript** – Interactive functionality and dynamic content.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/luiz-flix.git
```

### 2. Open the project folder

```bash
cd luiz-flix
```

### 3. Run the website

Open the `index.html` file in your preferred web browser.

No additional dependencies or installations are required.
